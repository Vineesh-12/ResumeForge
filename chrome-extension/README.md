# 🌐 ResumeForge AI — Chrome Extension

A lightweight, powerful browser extension that enables **1-click job description extraction** from any job board directly into ResumeForge.

---

## ⚡ Supported Job Platforms
- **LinkedIn Jobs** (`linkedin.com/jobs/*`)
- **Indeed** (`indeed.com/viewjob*`)
- **Greenhouse** (`boards.greenhouse.io/*`)
- **Lever** (`jobs.lever.co/*`)
- **Workday** & Company Career Portals

---

## 🛠️ How to Install in Google Chrome (or Edge / Brave)

1. Open your browser and navigate to:
   ```
   chrome://extensions
   ```
2. Enable **"Developer mode"** (toggle switch in the top right corner).
3. Click the **"Load unpacked"** button in the top left corner.
4. Select the `chrome-extension` folder inside this project directory:
   ```
   c:\Users\vinee\Downloads\JD\chrome-extension
   ```
5. Pin the **ResumeForge** icon to your browser toolbar!

---

## 🚀 How to Use It

1. Open any job posting on **LinkedIn**, **Indeed**, or any company careers page.
2. Click the **ResumeForge Extension** icon in your toolbar.
3. Click **"🚀 Extract Job & Tailor Resume"**.
4. The extension will automatically extract the job requirements, open [https://resume-forge-psi.vercel.app/](https://resume-forge-psi.vercel.app/), and pre-fill the job description!
